# 초등 수학 AI 튜터 API

학생의 풀이 기록으로 다음 문제를 추천하고, 공식 해설을 근거로 한국어 풀이를 설명해 주는 학습 지원 서비스입니다.

## 구성
- **DKT(지식 추적)**: 학생의 풀이 이력으로 정답 확률 예측 (AUC [값])
- **RAG 검색**: 문제·해설 임베딩 검색
- **추천**: 예측 확률 기반 난이도 맞춤 문제 추천
- **LLM 튜터**: 로컬 LLM(Ollama)이 공식 해설을 근거로 한국어 설명
- **번역**: 중국어 문제를 한국어로 번역 (숫자 보존 검사, 재시도, 원문 병기)
- **서빙**: FastAPI + Docker, 예측 지연시간 약 351ms (CPU)

## 실행
1. Ollama 실행 후 모델 준비: `ollama pull qwen2.5:7b`, `ollama pull gemma3:4b`
2. Ollama가 Docker 요청을 받게 설정: 환경변수 `OLLAMA_HOST=0.0.0.0:11434`
3. `docker compose up --build`
4. API 문서: http://127.0.0.1:8000/docs

## 알려진 한계
- 로컬 소형 모델이라 번역·설명이 틀릴 수 있습니다. 화면에 원문 병기와 경고를 두었습니다.
- 데이터가 중국어라 번역 단계가 필요합니다.
- 추후 개선: 한국어 데이터 교체, 더 큰 모델로 사전 번역 후 캐시.
